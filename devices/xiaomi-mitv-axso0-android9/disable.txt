# TV Glowup debloat list: Xiaomi MiTV-AXSO0, Android 9 (Amlogic "txlx"), 1 GB RAM.
# Built from this TV's own package list, cross-checked against AlPeFe/xiaomi-tv-debloat
# and the MiTV-AXSO0 list in Gathin23/cleanyourtv PR #25.
#
# install.sh runs `pm disable-user --user 0 <package>` for every line below.
# Nothing is uninstalled. Undo one: adb -s $TV shell pm enable <package>, or ./restore.sh for all.
#
# Deliberately KEPT: Xiaomi TV+ (com.mitv.tvhome.mitvplus), ZEE5, JioHotstar, Netflix, YouTube,
# Prime Video, Airtel Xstream, Play Store + Play Services, PatchWall (com.mitv.tvhome.atv, in case
# Xiaomi TV+ leans on it), all com.droidlogic.* / mitv.service / com.android.tv (HDMI, tuner, inputs),
# com.android.location.fused (boot-loop trap), Chromecast (mediashell), Miracast/MiLink/smartshare,
# Assistant (katniss), Google TV phone remote, firmware updates, USB media player and gallery,
# parental lock, and anything not clearly identified.
